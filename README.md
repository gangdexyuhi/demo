# Чудо Обувь — система оформления заказа обуви

Настольное приложение торговой компании **«Чудо Обувь»**: каталог моделей обуви,
оформление заказов клиентами и управление заказами менеджером и администратором.

## Используемые технологии

- Язык программирования: **Python 3** (3.8 и новее)
- Фреймворк интерфейса: **PyQt6** (при его отсутствии автоматически используется PyQt5)
- СУБД: **PostgreSQL** (драйвер `psycopg2-binary`)
- Импорт данных из Excel: `openpyxl`
- Сборка исполняемого файла: `PyInstaller`

## Назначение и основные функции

| Функция | Гость | Авторизованный пользователь | Менеджер | Администратор |
|---|:-:|:-:|:-:|:-:|
| Просмотр каталога | ✔ | ✔ | ✔ | ✔ |
| Поиск, фильтр по категории, сортировка по цене | — | ✔ | ✔ | ✔ |
| Просмотр карточки модели, оформление заказа | — | ✔ | ✔ | ✔ |
| Список заказов, состав заказа | — | — | ✔ | ✔ |
| Добавление и удаление заказов | — | — | ✔ | ✔ |
| Редактирование заказа (дата, удаление позиций) | — | — | — | ✔ |

**Каталог.** Для каждой модели выводятся изображение (или заглушка `picture.png`),
производство, наименование, категория, состав, суммарное количество пар по всем
размерам и цена со скидкой. Модели, которых осталось 3 пары и меньше, подсвечиваются
цветом `#ff8080`. Поиск (по наименованию и описанию, без учёта регистра), фильтр
по категории и сортировка по цене работают совместно и в реальном времени.

**Скидка.** На модели, которые не заказывали в предыдущем календарном месяце
(относительно текущей даты), действует скидка 25 %. Алгоритм — `app/discount.py`,
блок-схема — `docs/algorithm_flowchart.pdf`.

**Оформление заказа.** Из каталога открывается карточка модели с размерным рядом и
доступными размерами; выбирается размер и количество (не больше остатка). В заказ
можно добавить несколько позиций, изменить количество, удалить позицию или отказаться
от заказа. После подтверждения сохраняются клиент, дата, позиции и цены на момент
заказа, остатки на складе уменьшаются, каталог обновляется.

**Управление заказами.** Менеджер и администратор видят список заказов (дата, ФИО
клиента, сумма), состав заказа с итоговой суммой, могут оформить новый заказ на
любого клиента и удалить заказ (пары возвращаются на склад). Администратор может
изменить дату заказа и удалить отдельные позиции.

**Вход.** Только по логину из списка пользователей, пароль не нужен. Примеры:
`isivanov` — администратор, `papetrov` — менеджер, `asidorova` — авторизованный
пользователь. Можно продолжить как гость.

## Порядок подготовки базы данных

1. Установите PostgreSQL и pgAdmin, запомните пароль пользователя `postgres`.
2. Создайте базу данных `chudo_obuv` (pgAdmin: Databases → Create → Database).
3. Укажите свой пароль в `config.py` (поле `password`).
4. Разверните базу **одним из способов**:
   - из готового скрипта со структурой и данными: откройте Query Tool на базе
     `chudo_obuv` и выполните `database/chudo_obuv_dump.sql`
     (или `psql -U postgres -d chudo_obuv -f database/chudo_obuv_dump.sql`);
   - либо создайте таблицы и загрузите данные из Excel-файлов папки `import/`:
     `python database/import_data.py`.

## Порядок запуска приложения

```bash
python -m venv venv
venv\Scripts\activate          # Windows;  Linux: source venv/bin/activate
pip install -r requirements.txt
python main.py
```

Сборка исполняемого файла: Windows — `build_exe.bat` (`dist\ChudoObuv.exe`),
Linux — `sh build_exe.sh` (`dist/ChudoObuv`). Для работы ему нужен запущенный
PostgreSQL с базой `chudo_obuv`.

## Структура проекта

```

config.py                   параметры подключения к БД
app/
  db.py                     подключение и транзакции
  discount.py               алгоритм расчёта цены со скидкой

  order_draft.py            формируемый заказ
  data/                     запросы к БД (каталог, пользователи, заказы)
  views/                    страницы интерфейса
resources/                  логотип, иконка, заглушка, изображения товаров, styles.qss
database/
  schema.sql                скрипт создания таблиц
  import_data.py            импорт данных из import/*.xlsx
  chudo_obuv_dump.sql       скрипт БД со структурой и данными
  ERD_module_1.pdf          ER-диаграмма
import/                     исходные файлы заказчика (*.xlsx)
docs/                       блок-схемы алгоритмов, шпаргалка к экзамену
```
