# Команды (Linux) — всё, что нужно запомнить

## Сегодня, 14.10 (есть интернет)

```bash
git clone https://github.com/gangdexyuhi/demo ~/ChudoObuv
cd ~/ChudoObuv
bash setup.sh
bash run.sh
```

`setup.sh` сам ставит программы и PostgreSQL, создаёт базу `chudo_obuv` (пароль `postgres`),
venv с библиотеками и загружает данные. В конце должно быть «Готово!».

## Завтра, 15.10 (без интернета)

```bash
cd ~/ChudoObuv
bash run.sh
```

## Если что-то сломалось

| Что | Команда |
|---|---|
| База «упала» / connection refused | `sudo systemctl start postgresql` |
| Перезалить данные из xlsx | `source venv/bin/activate` и `python database/import_data.py` |
| Собрать исполняемый файл | `source venv/bin/activate` и `sh build_exe.sh` |
| Зайти в базу из консоли | `psql -h localhost -U postgres -d chudo_obuv` (пароль `postgres`) |
| Сделать скрипт БД | `pg_dump -h localhost -U postgres -d chudo_obuv --clean --if-exists --column-inserts -f dump.sql` |
| Библиотеки без интернета | `pip install --no-index --find-links wheels -r requirements.txt pandas` |
